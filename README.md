A modern, highly interactive web application built with cutting-edge front-end technologies. **Closess** focuses on delivering a seamless user experience with robust state management, beautiful animations, and a solid backend integration.

## ✨ Key Features

* **⚡ Blazing Fast:** Powered by [Vite](https://vitejs.dev/) for instant server start and lightning-fast HMR.
* **🎨 Modern UI:** Styled exclusively with [Tailwind CSS](https://tailwindcss.com/) and highly accessible components from [Radix UI](https://www.radix-ui.com/).
* ** انسيابية Motion:** Fluid and elegant animations implemented using [Framer Motion](https://www.framer.com/motion/).
* **🔐 Backend Ready:** Seamlessly integrated with [Firebase](https://firebase.google.com/) for authentication, database, and hosting.
* **📝 Type Safe Forms:** Complex form handling and validation utilizing [React Hook Form](https://react-hook-form.com/) and [Zod](https://zod.dev/).
* **📊 Data Visualization:** Beautiful charts and metrics rendered with [Recharts](https://recharts.org/).
* **🌙 Dark Mode:** Out-of-the-box theme management using `next-themes`.

## 🛠️ Tech Stack

* **Framework:** React 19 + TypeScript
* **Build Tool:** Vite
* **Routing:** React Router DOM
* **Styling & UI:** Tailwind CSS, Radix UI Primitives, Lucide React (Icons), Tailwind Merge & CLSX.
* **State & Data:** Firebase (v12)
* **Linting:** ESLint 9 + TypeScript ESLint
